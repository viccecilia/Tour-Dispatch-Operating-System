订单大厅属于会产生报价、接单及结算责任的高风险业务区，当前统一限定为车公司管理员使用。前端菜单与后端 GET/POST 权限一致，调度员、运管和司机均不可进入或调用。

## 已实施的收紧

- `/api/system/*` 和平台认证配置改为平台权限校验，不再仅凭 `role=admin` 放行。
- 订单、派车、资源、审计、组织成员、工作流、考勤、异常、日历和移动调度接口增加服务器端角色校验。
- `/api/driver/*` 只允许司机角色，且司机 ID 强制取自当前登录资料，不能用参数冒充其他司机。
- 司机读取派车证据前先验证该任务属于本人。
- 车公司账户、车辆、司机和订单继续强制租户过滤；客户端传入其他 `tenant_id` 无效。
- 平台创建账户缺少目标租户时由 500 更正为明确的 400。
- 非 demo 启动时拒绝默认 `admin123` 和默认 JWT 密钥；试用环境模板已改为强密码占位值。
- 后台菜单移除调度员/运管无权使用的自动化、设置等入口；司机账户不再进入车公司后台。
