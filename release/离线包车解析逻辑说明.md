# 离线包车解析与文书规则

适用文件：`daitora_offline_documents_v14_kix_hotels_resources.html`

## 两种录入方式

- **识别录入**：粘贴完整日文行程、简写包车，或“日期 + 司机 + 车辆尾号 + 单行路线”。
- **手动录入**：新建空白包车草稿，在左侧填写日期、时间、路线、司机、车牌、金额及备注。

两种方式最终写入同一份包车草稿，并生成一份《運送引受書》与一份《運行指示書》。下载时合成为一个多页 PDF。

## 已支持的识别格式

### 完整多日包车

```text
ツアーコード：SL420326A
人数：ゲスト4名+ガイド１名
ゲスト名：De Alba Juan Family
国籍：確認中（スペイン語圏）
車種：全日程アルファード

●10/3 9:00-17:00
Hyatt Regency Kyoto→清水寺→二年坂・三寧坂→Hyatt Regency Kyoto
```

识别：团号、客人、国籍、车型、每天日期、开始／结束时间、路线和后续地址／电话备注。

### 简写多日包车

```text
(DAVID MASSANET XICOLA 様)
10.19 09:00 京都市内包车 3代 阿尔法 日语司机1400
10/20 09:00 京都往返美山 3代 阿尔法 日语司机1600
1019 09:00 大阪市内包车 3代 阿尔法 日语司机1200
```

日期兼容：`10.19`、`10/19`、`10-19`、`10月19日`、`1019`、`2026-10-19`。

### 日配式单日包车

```text
10/3 杨正元 7047
大阪日航9:00出发-奈良公园-泡面博物馆（或者海游馆）-回酒店
```

识别：日期、司机、三／四位车辆尾号、开始时间、路线；并从车辆资料库带入完整车牌（如已维护）。未提供的客人、结束时间、金额保留为空白待填。

## 路线拆段规则

运行指示书不只显示一整行路线。路线中的下列分隔符会拆成相邻行程段：

`→`、`⇒`、`->`、`－`、`—`

例如：

```text
Hotel A → 清水寺 → 奈良公園 → Hotel A
```

生成运行指示书段：

1. Hotel A → 清水寺
2. 清水寺 → 奈良公園
3. 奈良公園 → Hotel A

首段带当天开始时间，末段带当天结束时间；中间时间留空，按实际行程填写。编辑“行程路线”后会自动重新拆段。

## 文书规则

### 运送引受书

与机场接送采用同一套字段：申请者、申请方式、运行开始／结束、乘降地点、料金、承运人地址、电话、紧急联系人及营业区域。

### 运行指示书

包含：营业所、运行管理者、司机、车牌、团号、人数与车型、全运行开始／结束、按路线拆出的每日行程段、安全指示与签字栏。

大阪营业所默认运行管理者：`胡東锴`。文书空字段留白，不显示“未入力”。

### 页数与下载

- 内容少于等于 10 单时使用紧凑单页。
- 内容较多时自动续页，不截断路线。
- 下载为一份合并多页 PDF，文件名包含包车第一天日期。
